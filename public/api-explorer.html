GET /api/categories

Devuelve las categorías del sitio como un array de strings en mayúsculas.

Request Chile Adicto
GET https://chileadictohoteles.cl/api/categories
200 OK
["CABANAS", "COSTA", "HOTELES", "LODGES", "NORTE", "PATAGONIA", "SUR"]
Request Santiago Adicto
GET https://santiagoadicto.cl/api/categories
GET /api/posts

Devuelve el listado de posts publicados del sitio. Soporta paginación con limit y offset.

Query Parameters
ParámetroTipoDescripción
limit1–100Máximo de resultados a devolver.
offsetnúmeroDesplazamiento para paginación. Defecto: 0.
Request Chile Adicto
GET https://chileadictohoteles.cl/api/posts
Request Chile Adicto — paginado (página 2, 10 por página)
GET https://chileadictohoteles.cl/api/posts?limit=10&offset=10
Request Santiago Adicto

GET /api/posts?categorySlug={slug}

Filtra los posts publicados por categoría usando el slug de la categoría. También soporta paginación.

Query Parameters
ParámetroTipoDescripción
categorySlugstringSlug de la categoría (ej: hoteles, museos). Obtenible desde /api/categories.
limit1–100Máximo de resultados a devolver.
offsetnúmeroDesplazamiento para paginación. Defecto: 0.
Request Chile Adicto — por categoría
GET https://chileadictohoteles.cl/api/posts?categorySlug=hoteles
Request Chile Adicto — por categoría + paginado
GET https://chileadictohoteles.cl/api/posts?categorySlug=hoteles&limit=10&offset=0
Request Santiago Adicto — por categoría
GET https://santiagoadicto.cl/api/posts?categorySlug=museos
Request Santiago Adicto — por categoría + paginado
GET https://santiagoadicto.cl/api/posts?categorySlug=museos&limit=10&offset=0
